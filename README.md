# Human Somatic Cancer Variant Calling Pipeline

## Overview

This repository contains a bioinformatics workflow for identifying and annotating somatic variants in human cancer sequencing data. 
The workflow includes sequencing quality control, read preprocessing, alignment to the human reference genome, 
alignment processing, variant analysis, and functional annotation.


## Workflow

1. **Raw read quality control** — FastQC is used to assess the quality of sequencing reads.
2. **Read preprocessing** — fastp is used for adapter trimming, filtering, and read-quality processing.
3. **Quality control reporting** — MultiQC combines quality-control reports into a single summary.
4. **Read alignment** — BWA-MEM2 aligns sequencing reads to the human reference genome.
5. **Alignment processing and variant analysis** — GATK, samtools, and bcftools support alignment processing and variant-related operations.
6. **Variant annotation** — Ensembl VEP annotates variants with predicted functional consequences and relevant genomic information.
7. **Downstream analysis** — R is used for statistical analysis, visualization, or interpretation, as implemented in the analysis scripts.

## Reference Genome and Annotation

- **Organism:** Human (*Homo sapiens*)
- **Reference genome assembly:** GRCh38
- **Variant annotation tool:** Ensembl Variant Effect Predictor (VEP)
- **VEP version:** 116


## Input Data

- **Tumour samples:** Sequencing reads derived from cancer tissue.
- **Matched normal samples:** Sequencing reads from non-tumour tissue.
- **Reference genome:** The human GRCh38 reference sequence and required index files.
- **Annotation resources:** The Ensembl VEP 116 offline cache for GRCh38.


## Output Files

- Sequencing quality-control reports.
- Trimmed and filtered FASTQ files.
- Aligned and processed BAM files and their index files.
- Variant call files in VCF or compressed VCF format.
- Variant annotation files generated by VEP.
- MultiQC summary reports.
- Analysis results and visualizations.
